# Password Policy

## Purpose

This policy defines the password requirements for all employees to ensure secure access to company systems.

---

## Password Requirements

Passwords must:

- Contain at least 12 characters
- Include uppercase letters
- Include lowercase letters
- Include numbers
- Include special characters

Example:

StrongPassword@123

---

## Password Expiration

Passwords must be changed every 90 days.

---

## Password History

The previous 5 passwords cannot be reused.

---

## Multi-Factor Authentication

MFA is mandatory for:

- VPN
- Azure Portal
- GitHub
- Microsoft 365
- Production Applications

---

## Storage

Passwords must never be stored in:

- Source Code
- Configuration Files
- Excel Sheets
- Email

Use Azure Key Vault or approved password managers.

---

## Prohibited Activities

Employees must never:

- Share passwords
- Write passwords on paper
- Send passwords through email
- Store passwords in plain text

---

## Account Lockout

Accounts will be locked after 5 consecutive failed login attempts.

---

## Reporting

Suspected password compromise must be reported immediately to the Information Security Team.
